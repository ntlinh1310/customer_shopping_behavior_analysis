# customer_shopping_behavior_analysis
Dự án này phân tích hành vi mua sắm của khách hàng dựa trên dữ liệu giao dịch từ 3.900 lượt mua hàng. Mục tiêu là khám phá insight về mô hình chi tiêu, phân khúc khách hàng, sở thích sản phẩm và hành vi đăng ký thành viên nhằm hỗ trợ doanh nghiệp đưa ra các quyết định chiến lược hiệu quả hơn. Sử dụng các công cụ SQL, Python, Power Bi để phân tích
